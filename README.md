# SketchCoil

SketchCoil is a real-time data processing engine for Geo-optimized coil-based systems, enabling scalable cloud deployments.

SketchCoil is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/SketchCoil.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

SketchCoil is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
